# Test data

Recorded NSmart API responses and a GSP Novi Sad timetable page, used to check parsing, cached GPS handling and arrival-time interpolation without network requests.

These data files were taken from the fixtures and samples in [katurov/NSBusTablica](https://github.com/katurov/NSBusTablica):

- `tests/fixtures/ispis_rvg_R_14.html`
- `samples/raw_6712_live_far.json`
- `samples/raw_6539_empty.json`

Original data sources: [NSmart](https://online.nsmart.rs/) and [GSP Novi Sad](https://www.gspns.rs/). These are historical test observations, not current bus positions or a current timetable.
